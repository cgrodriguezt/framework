Register a group of routes with a shared prefix and middleware.

Parameters
prefix:str | None, optionalURL prefix prepended to every route path in the group.
middleware:type[BaseMiddleware] | list | tuple | set | None, optionalMiddleware classes to attach to every route in the group. Accepts a single class or a container of classes.
without_middleware:type[BaseMiddleware] | list | tuple | set | None, optionalMiddleware classes to exclude from every route in the group. Accepts a single class or a container of classes.
routes:list[FluentRoute] | None, optionalFluentRoute instances to include in the group.
Returns
NoneRoutes are mutated and registered; no value is returned.
Raises
ValueErrorIf routes is empty or None.
ValueErrorIf prefix is not a str.
