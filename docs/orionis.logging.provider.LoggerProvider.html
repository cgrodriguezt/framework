overrides orionis.container.providers.ServiceProvider.boot

Initialize the logging system after all services are registered.

This method retrieves the logging configuration from the application, creates a Logger instance with this configuration, and initializes the Logger service. Ensures the logging system is ready after all providers have been registered.

Returns
NoneThis method does not return a value. It performs initialization as a side effect.
def register(self): (source) ¶
overrides orionis.container.providers.ServiceProvider.register

Register the Logger service implementation in the application container.

Bind the Logger class to the ILogger contract within the application's dependency injection container. Retrieve the logging configuration from the application, create a Logger instance using this configuration, and register it with an alias for internal framework identification.

Returns
NoneNo return value. Performs service registration as a side effect on the application container.
