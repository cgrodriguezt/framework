class OracleNencoding(Enum): (source)

View In Hierarchy

Represent Oracle encoding types for NCHAR and NVARCHAR2 data types.

This class defines constants for Oracle's national character set encodings. It can be extended to implement custom behaviors or properties related to Oracle's national character set encoding.
