View In Hierarchy

Register and boot the view system into the application container.

Registration phase

Binds IViewEnvironment → ViewEnvironment, IViewEngine → Jinja2Engine, and IViewFactory → ViewFactory as singletons.

Boot phase

Registers template globals, filters, and extensions with the ViewEnvironment singleton, then pins the View facade for zero-resolution access on the hot path.
