class StorageManager(IStorageManager): (source)

Constructor: StorageManager(app)

View In Hierarchy

Coordinate disk resolution for the storage component.

The manager reads the filesystems configuration, builds ~orionis.storage.disk.Disk objects bound to their drivers, and caches them per name. It knows nothing about files or directories: that behavior lives in the domain objects returned by each disk.
