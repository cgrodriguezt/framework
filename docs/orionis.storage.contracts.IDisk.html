class IDisk(ABC): (source)

Known subclasses: orionis.storage.Disk

View In Hierarchy

Define the contract for a configured storage disk.

A disk is the entry point to a storage backend. It builds ~orionis.storage.contracts.file.IFile and ~orionis.storage.contracts.directory.IDirectory objects bound to its driver and offers a small set of convenience methods that always delegate to those objects.
