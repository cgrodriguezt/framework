Instance Variable driver The driver type for the queue. Defaults to 'database'.
Instance Variable failed_jobs_table The name of the table used for failed jobs. Must match the pattern [a-z_]+ (lowercase letters or underscores only, no numbers).
Instance Variable jobs_table The name of the table used for the queue. Must match the pattern [a-z_]+ (lowercase letters or underscores only, no numbers).
Instance Variable max_attempts The maximum number of attempts for a job before it fails permanently. Must be a positive integer.
Instance Variable queue The name of the queue. Must contain only ASCII characters.
Instance Variable retry_delay The time in seconds to wait before retrying a failed job. Must be a positive integer.
Instance Variable strategy The strategy used for the queue. Options are FIFO, LIFO, or PRIORITY. Can be provided as a string (case-insensitive) or as a Strategy enum member.
Instance Variable visibility_timeout The time in seconds that a job is hidden from other workers after being fetched. Must be a positive integer.
