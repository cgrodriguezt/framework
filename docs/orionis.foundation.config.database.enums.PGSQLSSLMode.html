Define SSL modes for PostgreSQL connections.

This enumeration corresponds to the 'sslmode' parameter in libpq. The values determine the level of SSL enforcement and validation for PostgreSQL connections.

Returns
PGSQLSSLModeAn enumeration member representing the SSL mode.
Constant ALLOW Attempt SSL, silently fall back if unavailable.
Constant DISABLE No SSL (not secure).
Constant PREFER Use SSL if available (common default).
Constant REQUIRE Require SSL (no certificate validation).
Constant VERIFY_CA Validate the server certificate against the CA.
Constant VERIFY_FULL Validate both the certificate and the host name (most secure).
