class StateMixin: (source)

Known subclasses: orionis.orm.Model

View In Hierarchy

Attribute state tracking behavior shared by every model.

Tracks the original attribute snapshot taken at hydration or after the last successful save, the current attribute values, and the changes applied by the most recent save operation.

Method getChanges Return the attributes persisted by the last save operation.
Method getDirty Return the attributes modified since the last sync.
Method getOriginal Return the original attribute snapshot or a single original value.
Method isClean Report whether no attribute changed since the last sync.
Method isDirty Report whether any attribute changed since the last sync.
Method syncOriginal Snapshot the current attributes as the new original state.
Method wasChanged Report whether the last save operation changed any attribute.
