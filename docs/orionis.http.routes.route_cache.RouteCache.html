def __serializeCompiledRoute(cr: CompiledRoute) -> dict: (source) ¶

Convert a CompiledRoute to a JSON-safe dict.

regex and converters are omitted — they are fully deterministic from path and recomputed on deserialisation. Middleware class references are stored as dotted import paths.
