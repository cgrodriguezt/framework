class TranslationLoader(ITranslationLoader): (source)

Constructor: TranslationLoader(path)

View In Hierarchy

Load translation sources from the configured language path.

The loader reads root JSON files ({path}/{locale}.json) whose keys are the literal source texts, and grouped JSON files ({path}/{locale}/{group}.json) flattened with dot notation such as validation.required. Decoding is performed with msgspec for maximum throughput. The loader holds no cache: that concern belongs to the repository.
