class MemorySessionStore(ISessionStore): (source)

View In Hierarchy

In-process session store backed by a plain dictionary.

Suitable for development and testing. The internal dictionary is instance-scoped: separate instances never share state.

Notes

Thread safety is not guaranteed. Use this store only in single- threaded event-loop environments (the standard asyncio model).
