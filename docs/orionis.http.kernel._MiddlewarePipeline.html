class _MiddlewarePipeline: (source)

Constructor: _MiddlewarePipeline(instances, request, terminal)

View In Hierarchy

Iterative middleware pipeline that replaces per-request closure allocation.

A single instance encapsulates the execution state for one middleware stack invocation. Its __call__ method acts as the next() callable passed to each layer, advancing the pipeline without allocating closures or cells per request.
