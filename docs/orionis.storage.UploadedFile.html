class UploadedFile(IUploadedFile): (source)

Constructor: UploadedFile(source, manager)

View In Hierarchy

Represent a file received through HTTP, ready to be stored.

The object adapts the buffered multipart payload produced by the HTTP layer so it can be persisted onto any configured disk. It is fully decoupled from the request object and internally always delegates persistence to ~orionis.storage.file.File through the disk resolved by the manager.
