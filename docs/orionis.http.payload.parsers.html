def parse_urlencoded_multi(raw: bytes) -> dict[str, str | list[str]]: (source) ¶

Decode a URL-encoded payload, preserving duplicate-key semantics.

A key that appears once yields a plain string value. A key that appears more than once yields a list of strings in insertion order.

Parameters
raw:bytesURL-encoded bytes.
Returns
dict[str, str | list[str]]Parsed fields where single occurrences are scalars and repeated occurrences are lists.
