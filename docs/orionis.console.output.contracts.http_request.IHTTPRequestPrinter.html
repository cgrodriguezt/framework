Print a formatted HTTP request line to stdout or queue.

Computes the elapsed duration from start_time, builds an ANSI-coloured output line, and either enqueues it for the background worker (if start() was called) or writes directly to stdout.

Start the background print worker.

Creates the internal async queue and spawns a background task to drain queued output lines. Must be called once from an async context before the first request is handled.
