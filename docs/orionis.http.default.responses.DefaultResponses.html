def favicon(self) -> FileResponse | Response: (source) ¶
overrides orionis.http.default.contracts.responses.IDefaultResponses.favicon

Return the favicon file response or a 404 response if not found.

Searches for a favicon in the public storage directory using common favicon file names and content types. If not found, attempts to use the framework's internal fallback favicon. Caches the result for subsequent calls.

Returns
FileResponse or ResponseA FileResponse containing the favicon if found, otherwise a Response with status 404.
