Framework-agnostic description of a database column.

Column types such as ~orionis.orm.schema.types.Integer or ~orionis.orm.schema.types.String subclass this definition and expose a fluent API to declare constraints. The definition never touches the underlying SQL engine; the database compiler translates it later.
