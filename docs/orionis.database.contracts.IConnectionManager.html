Contract for the database connection manager.

The manager resolves the database configuration, registers named connection configurations, builds IConnection objects on demand, caches them for reuse, and controls their lifecycle.

Method addConnection Register or replace a named connection configuration at runtime.
Method connection Resolve the connection registered under the given name.
Async Method disconnect Dispose one or all cached connections.
Method getDefaultName Return the name of the default connection.
Method hasConnection Report whether a connection configuration exists.
