Enumerate supported MySQL storage engines.

This enum is used to specify the storage engine for MySQL database tables.

Returns
MySQLEngineAn enumeration member representing a MySQL storage engine.
Constant INNODB Default transactional storage engine, supports ACID compliance and foreign keys.
Constant MEMORY Stores all data in RAM for fast access, data is lost on server restart.
Constant MYISAM Legacy non-transactional storage engine, faster for read-heavy workloads but lacks transaction support.
Constant NDB Clustered storage engine designed for distributed MySQL setups.
