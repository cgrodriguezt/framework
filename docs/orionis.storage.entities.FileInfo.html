class FileInfo: (source)

View In Hierarchy

Immutable snapshot of a stored file's metadata.

Instances are produced by storage drivers and returned by await file.info(). All values reflect the state of the file at the moment the snapshot was taken.

Instance Variable checksum SHA-256 hex digest of the content, or None when unavailable.
Instance Variable createdAt Timezone-aware creation timestamp, or None when the driver cannot provide it.
Instance Variable etag Entity tag of the content (MD5 hex digest for built-in drivers), or None when unavailable.
Instance Variable lastModified Timezone-aware timestamp of the last modification.
Instance Variable mimeType Guessed MIME type, or None when it cannot be determined.
Instance Variable path Canonical root-relative path of the file on its disk.
Instance Variable size File size in bytes.
Instance Variable url Public URL of the file, or None when the disk does not expose URLs.
Instance Variable visibility Visibility level of the file ('public' or 'private').
