View In Hierarchy

Render named templates and return HTMLResponse objects.

ViewFactory is the primary entry-point for controllers and other HTTP-layer code that needs to produce HTML responses from templates. It delegates all rendering work to the bound IViewEngine and wraps the output in a framework-native HTMLResponse.
