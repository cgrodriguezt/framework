class documentation

class ModelQueryBuilder(IModelQueryBuilder): (source)

Constructor: ModelQueryBuilder(model)

View In Hierarchy

Fluent, chainable query builder bound to a model class.

The builder accumulates an engine-agnostic SelectPlan and delegates execution to the model connection, hydrating results into model instances wrapped in a Collection.
