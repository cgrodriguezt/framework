Async context manager driving a connection-level transaction.

Entering the context begins a transaction on the wrapped connection (a savepoint when one is already active); leaving it commits on success and rolls back when an exception escapes the block.

Async Method __aenter__ Begin the transaction and enter the context.
Async Method __aexit__ Commit or roll back the transaction when leaving the context.
