class ConnectionManager(IConnectionManager): (source)

Constructor: ConnectionManager(app)

View In Hierarchy

Resolve, cache, and control the lifecycle of database connections.

The manager reads the database configuration, keeps one plain configuration mapping per connection name, and builds Connection objects lazily, caching them for reuse.

Notes

This module must not enable from __future__ import annotations: the container resolves constructor dependencies from evaluated annotations, and stringized annotations cannot be injected.
