class CacheRepository(ICacheRepository): (source)

Constructor: CacheRepository(backend, prefix)

View In Hierarchy

Async cache repository backed by a configurable storage backend.

Wraps a low-level backend with optional key-prefix support and exposes a higher-level API (get, set, remember, lock, …).

Method __init__ Initialise the repository with a backend and an optional key prefix.
Method _k Return the prefixed form of key.
