class App(BaseEntity): (source)

Represent application configuration settings.

Parameters
nameThe name of the application. Default is 'Orionis Application'.
envThe environment in which the application is running. Default is 'DEVELOPMENT'.
debugWhether debug mode is enabled. Default is True.
timezoneThe timezone of the application. Default is 'UTC'.
localeThe locale for the application. Default is 'en'.
fallback_localeThe locale used when a translation is missing. Default is 'en'.
language_pathRelative path to the JSON translation files. Default is 'resources/lang/'.
cipherThe cipher used for encryption. Default is 'AES_256_CBC'.
keyThe encryption key for the application. Default is None.
maintenanceThe maintenance route for the application. Default is '/maintenance'.
