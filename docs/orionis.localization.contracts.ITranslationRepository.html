Define the contract for the in-memory translation cache.

The repository guarantees that each locale is read from disk at most once, keeping every subsequent lookup fully in memory with O(1) access.

Method flush Discard every cached translation map.
Method forget Discard the cached translations for locale.
Method get Return the translation map for locale, loading it on demand.
