Define the contract for an uploaded file held in memory or on disk.

Implementations buffer incoming bytes via write(), optionally spill to a temporary file, and expose content through read() and save().

Method chunks Iterate over the file content in fixed-size chunks.
Method close Close the file handle and release all associated resources.
Method read Read the entire file content from the beginning.
Method replace Replace the file content with data and update the byte counter.
Method save Write the file contents to path on the local filesystem.
