class IModelQueryBuilder(ABC): (source)

Known subclasses: orionis.orm.query.ModelQueryBuilder

View In Hierarchy

Contract for the fluent model query builder.

Fluent methods return the builder itself for chaining; terminal methods execute the accumulated query against the model connection.
